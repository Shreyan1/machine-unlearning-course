# Hall of Finishers

Everyone here passed the [final test](final.md) and asked to be listed. They appear in the order they finished, so
the number next to a name is their place in the queue, not a score ranking. Scores are typed in by the learners, so
ranking by them would only reward whoever typed the biggest number.

<!-- finishers -->

## Verify a certificate

Every certificate carries an ID such as `MU-ABCD-2345`. Type it here to see whether it belongs to someone on the list.
Certificates are made in the learner's browser, so only a listed ID has been checked by a person.

## How to join

1. Score 16 or more on the [final test](final.md).
2. Open [your certificate](certificate.md), type your name and download the image.
3. Press **Join the Hall of Finishers**, attach the image to the GitHub issue that opens and submit it.

Each request is checked by hand before a name is added. The certificate must show a passing score and its ID, and the
name must match the requester's GitHub profile or a LinkedIn profile they link. To be removed, open an issue or email
the author; see [About](../about.md).
